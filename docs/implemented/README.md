# Implemented ✅

Tudo que é **verdadeiro agora**: código de feature entregue e **alcançável**, mais o corpus estável que o
sustenta (decisões aceitas, runbooks, templates). Um doc aqui significa "isto é real e usável de ponta a ponta".

- **Mudar comportamento entregue:** mudança **pequena**, edite a spec implementada no mesmo PR do código;
  mudança **grande** ou reescrita, escreva uma spec delta em [`../planned/`](../planned/README.md) (a spec
  implementada segue como a verdade viva até o delta graduar). Ver o
  [ciclo de vida da feature](../../.claude/rules/common/feature-lifecycle.md).
- **Decisões técnicas** vivem na seção **Decisões** do doc de arquitetura ou de produto que as usa; não há
  ledger nem arquivo de ADR.
