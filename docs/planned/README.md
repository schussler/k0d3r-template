# Planned 🔲

Specs **à frente do código**: escritas e acordadas, mas ainda não entregues (ou construídas e ainda não
alcançáveis). É o backlog docs-first: a spec lidera, e a própria pasta declara a distância até o trabalho
começar; aí ela vai para [`../in-progress/`](../in-progress/README.md) com `git mv`, pelo
[ciclo de vida da feature](../../.claude/rules/common/feature-lifecycle.md).

A árvore (`arquitetura/`, `produto/`, `processo/`) é o índice; não há lista mantida à mão aqui. O que ficou para
depois e ainda não tem desenho é uma linha no [`backlog.md`](backlog.md), não uma spec.
