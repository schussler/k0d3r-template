# Backlog do projeto

O que ficou para depois e ainda não tem desenho: a parte de uma feature que não entrou na entrega, um defeito
achado fora do caminho de uma tarefa. Uma linha por item. Quando alguém pega o item, a `/k0d3r-task` o classifica
(correção, ajuste pontual, delta ou spec nova) e a linha sai daqui no mesmo commit.

O que já tem desenho escrito e aprovado fica como spec em `planned/`, não aqui. O backlog do toolset `.claude/`
fica em [`processo/toolset-backlog.md`](processo/toolset-backlog.md).
