# Produto (em código agora)

**Entra:** Specs de feature, regras de negócio, telas e fluxos, a partir do [template de spec](../../implemented/processo/feature-spec-template.md).

**Não entra:** Decisões de infraestrutura (vão em `arquitetura/`) e o processo de trabalho (vai em `processo/`).

Vazia entre sprints: uma spec fica aqui só enquanto a feature está em código.
