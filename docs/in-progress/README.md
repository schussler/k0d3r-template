# In progress 🚧

**Vazia entre sprints, por desenho.** Esta pasta guarda uma spec só enquanto a feature está em código
*agora*. Entre sprints, todo doc vive em [`../implemented/`](../implemented/README.md) (feito e alcançável) ou
em [`../planned/`](../planned/README.md) (ainda não construído, ou construído e não alcançável). Feature
parcial é **dividida** de volta para `planned/`, nunca estacionada aqui.

A entrada e a saída (`git mv` ao começar, plano de build escrito dentro da spec, graduação com aprovação humana
na sessão) estão no [ciclo de vida da feature](../../.claude/rules/common/feature-lifecycle.md). Uma iniciativa
grande pode ter um roadmap na raiz desta pasta enquanto durar (ver a seção de iniciativas da mesma regra).
