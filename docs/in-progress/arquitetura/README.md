# Arquitetura (em código agora)

**Entra:** Sistema, stack, modelo de dados, infraestrutura e as decisões técnicas (na seção **Decisões** de cada doc).

**Não entra:** Specs de feature (vão em `produto/`) e runbooks (vão em `processo/`).

Vazia entre sprints: uma spec fica aqui só enquanto a feature está em código.
